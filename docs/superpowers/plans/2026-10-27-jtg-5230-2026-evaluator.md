# JTG/T 5230—2026 评定参数包与评分器实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 新增 JTG/T 5230—2026 规则包（草稿状态，运行时不加载），以及按“构件 → 桥跨 → 单元 → 全桥”计算的 C++ 评分器；每条公式和分档边界都有测试。

**架构：** 加载器放开 `draft` 状态，运行时扫描收进 `StandardPackageLoader::load_runtime_packages`，遇到草稿就跳过。规则包由 8 个 JSON 入口文件组成。`Jtg5230Parameters` 把包解析成强类型参数，并做一致性校验。`Jtg5230Evaluator` 实现新接口 `LayeredTechnicalConditionStandard`，只使用解析好的参数；桥跨和全桥指数用整数分数精确计算，再按十进制四舍五入。

**技术栈：** C++20、jsoncpp、GoogleTest；CMake + VS 2022 多配置构建目录。

**设计：** [docs/superpowers/specs/2026-10-27-jtg-5230-2026-evaluator-design.md](../specs/2026-10-27-jtg-5230-2026-evaluator-design.md)。执行者须同时阅读，尤其是第 2 节（条文摘要）和第 8 节（写计划时的补充）。

## 审查重点

1. **显式权重套被绕开。** 拱桥（表 B.3.3～B.3.8）选了“设伸缩装置”那套权重，又把伸缩装置列为全桥无须设置。按比例换算会得出 53.3 / 26.7 / 20，而规范第二列是 50 / 30 / 20。期望 `validate` 拒绝，并提示改选 `without_expansion_joint`。→ 任务 4（`explicit_weight_set_available`）、任务 6（`ExplicitWeightSetIsUsedAsPrinted`）。
2. **x.x5 的舍入。** 整体式板桥只有河床 ECI 为 1 时，BSCI 精确值是 99.65，双精度算出来是 99.6499…，期望 99.7。两跨等级一致、取平均值时同理。→ 任务 6（`RoundsSpanIndexHalfUpInDecimal`）、任务 7（`UniformGradesAverageRoundedSpanIndices`）。
3. **部分为主要构件的部件没标。** 腹拱墩和侧墙、横梁纵梁及桥面板、支座及约束体系，这三种部件的构件不给 `is_main` 时，期望拒绝，不默认成主要或非主要。→ 任务 4、任务 5。
4. **共用构件。** 两跨共用的桥墩、拼宽结构新旧共用的构件，期望每个相关桥跨都按它的 ECI 计入。→ 任务 6（`SharedComponentCountsInBothSpans`）、任务 7（`ComponentSharedAcrossUnitsCountsInEach`）。
5. **改判条件不全。** 以下四种情况都不改判：非主要构件、ECL < 4、没标“影响桥梁安全”、算出的等级已经同样差。→ 任务 6 的四个改判用例。

**计算（设计 4.3 第 2～4 步）。** 一律用整数分数，不经过 double：

```cpp
// 十分位为单位的桥跨扣分 = Σ_s 2·γ_s·S_s / d_s
//   γ_s：结构 s 的影响系数百分数（0.15 → 15）
//   S_s = Σ CI(j)·ω(j)，只算结构 s 内、未列为无须设置的部件
//   d_s = 这些部件的 ω 之和（没有重分时为 100）
// BSCI（十分位）= round_half_up(1000 − 扣分)
struct Fraction { std::int64_t numerator; std::int64_t denominator; };  // 分母 > 0，每次运算后用 std::gcd 约分
// 非负分数四舍五入到整数：floor((2n + d) / (2d))，全程整数运算
int round_half_up(Fraction value);
```

- `CI(j)`：所有 `span_ids` 含本跨、`part_id` 为该部件的构件，取其 ECI 的最大值。`worst_component_id` 取输入顺序中第一个达到最大值的构件；没有这样的构件时，`CI = 0`、id 为空。
- 展示字段：`effective_omega = ω·100.0/d_s`，`gamma = γ_s/100.0`，`contribution = ci·effective_omega·gamma/5.0`。
- 先由 `classify_span` 得出计算等级。
- 改判：
  - 候选构件同时满足：`span_ids` 含本跨、`is_main`、`ecl ≥ 4`、`affects_bridge_safety`；
  - 取 ECL 最大者，同 ECL 时取输入顺序第一个；
  - 它的 ECL 大于计算等级时，`grade` 取该 ECL，`index` 取 `index_limit_tenths` 中对应的上限，`override_component_id` 记它的 id；
  - 否则 `index`、`grade` 等于计算值。
- 轨迹：
  - 每跨：`step = "span"`，`rule_id` 为参数表 id，`entity_id` 为桥跨 id，`source_reference = "3.3.1、表 3.3.2"`；`inputs` 记 `unit_id` 和各部件的 `part_id`、`ci`、`effective_omega`、`gamma`；`output` 记 `index`、`grade`（计算值）。
