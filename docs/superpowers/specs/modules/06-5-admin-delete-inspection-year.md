# 模块 06.5 补充设计：管理员永久删除年度检测

> 日期：2026-07-15
>
> 状态：已实施并通过自动化回归（2026-07-15）
>
> 关联设计：`docs/superpowers/specs/modules/06-5-bridge-centric-interaction-redesign.md`

## 1. 背景与目标

模块 06.5 已支持在桥梁内新建年度检测，但尚不能清理误建或整体错误的年度。管理员需要在年度工作台中永久删除指定桥梁、指定年度的全部数据。

本功能采用 C1 语义：管理员删除“2026 年度”时，不只删除当前 V2，而是永久删除该桥梁 2026 年的 V1、V2 等全部版本以及它们的年度业务数据。删除不可恢复，因此必须提供实时影响预览、强确认、并发保护、删除审计和文件清理补偿。

## 2. 已确认决策

1. 只有管理员可以看到和调用永久删除功能。
2. 待校对、已确认、已归档和已被修订年度均可永久删除。
3. 删除范围按“桥梁 + 检测年度”确定，同年度所有版本一次删除。
4. 删除年度的导入记录、草稿、正式病害、尺寸、照片、评分、原始 Word、解析图片和独占归档文件。
5. 删除所有引用目标年度的病害对比结论。
6. 跨年病害线索保留其他年度观测并重算首次、最近出现年度；没有剩余观测的空线索删除。
7. 桥梁构件属于跨年度基础档案，不随年度删除。
8. 被其他数据继续引用的共享归档文件保留；响应只报告保留数量，不暴露路径。
9. 存在有效编辑锁时禁止删除，管理员需先通过已有能力解除锁。
10. 数据库事务提交后才允许物理删除文件；失败文件进入持久清理队列。
11. 删除审计永久保留元数据和数量快照，但不保留已删除的年度业务内容。

## 3. 非目标

1. 不提供回收站、撤销删除或年度恢复。
2. 不提供“只删除 V2 并恢复 V1”的版本回滚。
3. 不删除桥梁、桥梁构件或其他年度仍在使用的数据。
4. 不新增删除审计查询页面；第一版只持久化审计记录。
5. 不允许普通用户提交删除申请或等待管理员审批。
6. 不在本功能中重新设计模块 07 的病害对比业务。

## 4. 页面交互

### 4.1 删除入口

年度工作台标题区保持现有“状态、导入资料”操作，在其右侧增加管理员专属“更多”菜单：

```text
2026 年度检测                         已确认   导入资料   更多 ▾
                                                   └─ 永久删除年度
```

普通用户不渲染“更多”和删除入口。年度左侧年份卡不放删除按钮，避免切换年度时误操作。V1、V2 不分别提供删除入口，因为删除目标始终是整个年度。

### 4.2 影响预览弹窗

点击删除后先获取后端实时影响范围。加载成功前不显示可提交确认表单。弹窗显示：

- 桥梁名称、系统编号和检测年度；
- 年度版本数及版本列表；
- 导入记录、病害观测、尺寸、正式照片、评分项数量；
- 原始 Word、解析图片和其他独占归档文件数量；
- 受影响的跨年线索和病害对比数量；
- 因仍被其他数据引用而保留的共享文件数量；
- 当前活动编辑锁及编辑人。

存在活动编辑锁时，弹窗显示编辑人和锁定时间，永久删除按钮保持禁用，并提示管理员先使用已有强制解锁流程。

管理员必须填写非空删除原因，并准确输入后端返回的确认文字，例如 `永久删除 2026`。只有两个字段都合法且没有活动锁时，红色“永久删除”按钮才启用。提交期间禁止关闭弹窗、切换年份和重复提交。

### 4.3 删除完成后的导航

删除成功后显示：

> 已永久删除绕阳河二号桥 2026 年度检测及其全部版本。

页面刷新桥梁概览和年度列表，自动进入剩余最新的当前年度；如果没有剩余年度，则停留在年度检测空状态。

## 5. API 合同

### 5.1 获取删除影响范围

```http
GET /api/inspection-years/{inspection_year_id}/deletion-impact
```

要求登录且角色为管理员。路径中的任意年度版本 ID 只用于定位桥梁和检测年度，响应聚合该年度的全部版本。

成功响应：

```json
{
  "bridge": {
    "id": "...",
    "system_number": "QL-001287",
    "bridge_name": "绕阳河二号桥（模块05样例）"
  },
  "inspection_year": 2026,
  "version_numbers": [1, 2],
  "counts": {
    "inspection_versions": 2,
    "import_records": 3,
    "defect_observations": 25,
    "defect_measurements": 18,
    "defect_photos": 31,
    "condition_ratings": 38,
    "archived_files_to_delete": 33,
    "shared_files_retained": 0,
    "defect_threads_affected": 12,
    "defect_comparisons": 4
  },
  "active_edit_locks": [],
  "confirmation_text": "永久删除 2026",
  "impact_token": "sha256:..."
}
```

响应不得包含绝对路径或 `storage_relative_path`。

### 5.2 执行永久删除

```http
DELETE /api/inspection-years/{inspection_year_id}
Content-Type: application/json

{
  "reason": "该年度导入了错误桥梁的报告",
  "confirmation_text": "永久删除 2026",
  "impact_token": "sha256:..."
}
```

后端必须独立验证管理员角色、确认文字、非空原因、活动编辑锁和影响令牌。前端禁用按钮不能替代后端校验。

成功响应：

```json
{
  "deleted": true,
  "bridge_id": "...",
  "inspection_year": 2026,
  "deleted_counts": { "inspection_versions": 2 },
  "file_cleanup_pending_count": 0,
  "next_inspection_year_id": "..."
}
```

`next_inspection_year_id` 没有剩余当前年度时为 `null`。

### 5.3 稳定错误码

- `unauthorized`：未登录，401；
- `forbidden`：非管理员，403；
- `inspection_year_not_found`：定位年度不存在，404；
- `invalid_deletion_request`：原因或确认文字无效，400；
- `inspection_year_deletion_locked`：存在活动编辑锁，409，并返回不含令牌的锁摘要；
- `inspection_year_deletion_impact_changed`：实时影响范围与令牌不一致，409，要求重新预览；
- `inspection_year_delete_failed`：事务执行失败，500。

## 6. 影响令牌与并发控制

影响预览按稳定顺序收集目标年度版本、导入记录、年度事实、文件、线索和对比的主键及必要并发字段，编码为规范 JSON 后计算 SHA-256。令牌只用于检测预览后数据变化，不承担授权作用。

执行删除时在单个数据库事务内：

1. 重新定位“桥梁 + 年度”并锁定全部年度版本；
2. 锁定目标导入记录和年度事实；
3. 重新计算规范删除计划和影响令牌；
4. 令牌不一致则回滚并返回 409；
5. 再次查询 `expires_at > now()` 的活动编辑锁；
6. 有锁则回滚并返回 409；
7. 无冲突才执行删除。

这样可以拦截弹窗打开后发生的新导入、保存草稿、正式入库、照片关联和对比确认。

## 7. 数据库设计

### 7.1 删除审计

新增 `inspection_year_deletion_audits`：

- `id`、`system_number`；
- `bridge_id`，允许桥梁后续删除时 `on delete set null`；
- 桥梁系统编号、名称快照；
- `inspection_year`；
- 操作用户 ID、用户名和显示名快照；
- `reason`；
- `impact_json` 和 `deleted_counts_json`；
- `file_cleanup_status`：`待清理`、`已完成`、`部分失败`；
- `created_at`、`file_cleanup_completed_at`。

审计表不得外键引用即将删除的 `inspection_years` 或 `import_records`。

### 7.2 文件清理队列

新增 `archived_file_deletion_queue`：

- `id`；
- `deletion_audit_id`；
- 已验证的安全相对路径；
- `status`：`待清理`、`已完成`、`失败待重试`；
- `attempt_count`、`last_error`；
- `created_at`、`completed_at`。

相对路径只供后端内部清理器使用，任何 API 响应均不得返回。清理器仍必须通过 `resolve_path_under_root` 验证路径，不能直接拼接磁盘路径。

## 8. 数据删除事务

数据库事务按以下逻辑执行：

1. 生成审计快照和待清理文件清单；
2. 删除 `current_inspection_year_id` 或 `compared_inspection_year_id` 命中目标版本的病害对比；
3. 删除目标年度导入记录及其文件关联、草稿状态和编辑锁；
4. 删除目标年度病害观测，依靠既有外键级联清理尺寸和正式照片；
5. 删除目标年度评分；
6. 清除目标版本之间的修订引用并删除全部年度版本；
7. 对受影响线索按剩余正式观测重算 `first_seen_inspection_id` 和 `latest_seen_inspection_id`；
8. 删除没有任何剩余观测的空线索；
9. 删除已无任何数据库引用的候选 `archived_files`；仍被其他数据引用的文件计入 `shared_files_retained`；
10. 更新审计删除数量并提交事务。

桥梁构件、其他年度观测和仍有观测的跨年线索必须保留。删除顺序由仓储层显式控制，不依赖一个未经审计的通用级联删除。

## 9. 文件系统补偿

数据库事务期间不删除磁盘文件。事务提交成功后，后端立即处理本次审计的文件清理队列：

1. 对每个相对路径再次执行根目录边界检查；
2. 文件不存在视为幂等成功；
3. 删除成功标记队列项 `已完成`；
4. 删除失败记录错误和尝试次数，标记 `失败待重试`；
5. 汇总更新审计的文件清理状态。

后端启动时以有界批次重试未完成队列，避免一次启动无限阻塞。数据库删除已经提交后，文件失败不恢复年度业务数据。

## 10. 后端组件边界

- `InspectionYearDeletionPlanner`：只负责构造规范影响计划、计数和影响令牌；可使用纯模型测试。
- `InspectionYearDeletionRepository`：负责权限外的数据库锁定、令牌复核、审计和删除事务。
- `ArchivedFileDeletionQueue`：负责安全路径验证、物理删除、状态更新和启动重试。
- `InspectionYearDeletionRoutes`：负责鉴权、管理员角色、请求校验、稳定错误码和响应脱敏。

删除逻辑不塞入现有 `WorkspaceRepository`，避免工作区查询、年度创建、Word 上传和高风险删除混在同一仓储类中。

## 11. 前端组件边界

- `AnnualWorkspace` 只根据管理员角色显示“更多”菜单并打开弹窗；
- `DeleteInspectionYearDialog` 管理预览、原因、确认文字、提交状态和错误恢复；
- `workspaceApi` 增加 `fetchInspectionYearDeletionImpact` 与 `deleteInspectionYear`；
- 删除成功后由 `InspectionWorkspacePage` 刷新年份、概览并按 `next_inspection_year_id` 导航。

弹窗关闭后不缓存影响令牌；每次重新打开都重新获取实时预览。

## 12. 测试与验收

### 12.1 后端

1. 未登录 401、普通用户 403、管理员可预览和删除；
2. 同年度 V1、V2 一起删除；
3. 导入记录、草稿、病害、尺寸、照片和评分全部删除；
4. 目标年度对比删除；
5. 跨年度线索保留其他年度并正确重算首末年度；
6. 空线索删除，桥梁构件保留；
7. 独占归档元数据删除，共享文件保留；
8. 活动编辑锁返回 409；
9. 影响范围改变后旧令牌返回 409；
10. 原因和确认文字由后端独立验证；
11. 数据库事务失败时磁盘文件不动；
12. 文件删除失败进入队列并可幂等重试；
13. 预览、成功和错误响应不泄漏路径。

### 12.2 前端

1. 普通用户看不到删除入口，管理员可见；
2. 弹窗先加载影响预览；
3. 原因或确认文字缺失时按钮禁用；
4. 活动锁显示编辑人并禁止提交；
5. 提交期间防重复并禁止关闭；
6. 409 数据变化提示重新预览；
7. 删除成功进入剩余最新年度；
8. 无剩余年度显示空状态；
9. 已有新建年度、导入、解析、校对和构件档案测试继续通过。

## 13. 风险控制

1. **误删正式档案**：管理员限定、实时预览、原因、精确确认文字和不可恢复警告共同控制。
2. **预览后数据变化**：影响令牌和数据库行锁控制。
3. **正在编辑时删除**：活动租约锁阻断，不能由删除接口隐式强制解锁。
4. **破坏跨年线索**：只删目标观测，重算线索首末年度，仅删除空线索。
5. **文件与数据库不一致**：先提交数据库，后处理持久文件清理队列。
6. **共享文件误删**：提交前复核所有数据库引用，只清理无引用文件。
7. **接口泄漏归档路径**：路径只存在于后端内部队列表，API 只返回数量。
