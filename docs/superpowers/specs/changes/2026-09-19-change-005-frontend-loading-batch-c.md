# 变更提案 005：C 批次——前端按需加载与依赖整理

日期：2026-09-19。用户已确认聊天方案并授权先写技术文档后实施。范围限于前端加载方式与依赖整理；保留 P1、A、B 批次及已有工作区差异。

## 1. 问题与目标

App 静态导入所有业务页面，构件评分组件静态引用图表库，桥梁列表静态导入仅打开时才使用的管理面板和创建向导。B 批次生产入口约 3.22 MB、gzip 996 KB。仅把一个大文件改成几个同时加载的文件不能算优化。

目标为登录与当前页面只加载必要的模块；无评分不加载图表，未打开规范面板/创建桥梁不加载相应代码；加载失败有可恢复提示，保持身份恢复、工作区外壳、年度隔离、草稿和旧路由行为。

## 2. 方案选择与边界

采用已确认的“页面 + 图表 + 重点面板 + 依赖整理”。仅页面拆分不能覆盖无评分和隐藏面板；同时升级 Vite/React、替换图表库或重构业务状态会扩大风险。本批保留当前依赖版本与评分、API、数据库合同，不进行后端改造。

不改变大型页面内部业务状态，不添加全局状态框架、预取所有页面或自动刷新机制。代码和文档留在工作区，不提交或部署。

## 3. C1：建立可复现基线

提供使用 Vite 正式构建的分析脚本，记录 chunk 大小、gzip 估算、静态/动态依赖及源模块归属；计算入口静态依赖闭包的总量，避免只比较入口文件。

改动前保留独立 production dist 和报告；改动后同环境重测。浏览器使用生产产物和独立模拟 API 验证资源请求，覆盖登录、工作台、桥梁列表、构件档案、面板与失败恢复。模拟 API 只提供合成数据，不连接业务数据库；结果明确区分本机合成测量与真实业务性能。

## 4. C2：页面边界

使用 React.lazy 与动态 import 加载业务页面。登录/会话恢复、认证 Provider、AppLayout、BridgeWorkspaceShell 维持稳定；页面级 Suspense 与错误边界放在壳内。桥梁子路由切换不重建桥梁壳及其上下文。

同一页面的参数变化不通过全局 pathname key 强制重建页面，沿用既有年度/桥梁隔离机制。旧整理地址继续重定向。模块只从明确文件导入，避免静态 barrel 意外把页面重新拉回启动链。

## 5. C3：图表边界

ComponentRatingSummary 保留评分排序、空态与数据整理。实际 Line 图表移到独立模块；有效评分点非空时才渲染加载边界。保留原主题 token、动态坐标范围、评分精度、标注与提示。

加载等待/失败时提供年份与评分文字，图表失败不影响构件档案。图表重试只重置图表边界，不清空档案其他状态。

## 6. C4：重点面板

优先在 BridgesPage 已有条件挂载位置懒加载 StandardsAdminPanel 和 CreateBridgeDialog。创建桥梁向导整体作为独立模块，表单的步骤、选择和创建后重试语义保持原样。

加载中或失败仍可取消打开操作。关闭会卸载该次边界；迟到的模块完成不重新打开面板。再次打开复用成功加载的模块，但维持原本新建表单的初始化行为。

## 7. C5：依赖及分包

全源码/配置核查后移除未使用的 @ant-design/pro-components，更新 package.json/package-lock.json；将构建插件归入 devDependencies，不升级版本。

首先使用 Vite/Rollup 自然分包，不统一打包全部 node_modules。若静态依赖闭包证明共享 chunk 意外带入图表/页面，再针对实际依赖边界调整。保留体积警告阈值，新增构建图检查防止图表、复杂页面和隐藏面板回流首屏。

## 8. C6：加载与故障恢复

公共轻量加载组件区分加载中、加载模块失败和组件渲染失败。加载占位保留区域高度并提供可访问状态文字；失败提供明确重试与返回/取消操作。

重试创建新的 lazy 尝试，并清除本组件保存的拒绝 promise；成功模块缓存共享。浏览器自身对失败模块 URL 的缓存可能仍阻止恢复，连续失败提供手动重新加载提示，不无限重试、不拼随机 query 绕过打包。

不自动刷新页面或重放业务提交。提示重新加载前明确未保存内容风险；由用户主动操作。局部失败不销毁已有外壳或其他业务区域。

## 9. 实施顺序

1. 写入本规格，读取现有路由、认证、面板与测试；生成改动前构建基线。
2. 实现可重试加载边界及针对加载/失败/缓存/卸载的测试。
3. 迁移业务页面，验证身份恢复、直达路由、旧重定向与壳保留。
4. 拆分图表，覆盖无数据、全空评分、有评分、失败文字兜底。
5. 拆分两个重点面板，验证取消、再次打开和原业务流程。
6. 整理依赖并验证锁文件复建；生成改动后构建图与资源对比。
7. 前端完整测试、生产浏览器验证、Ant Design lint；同步入口文档与验收记录。

## 10. 验收与回退

- 改动前后均记录入口静态闭包总量与实际请求；无未经实测的提速承诺。
- 登录不加载业务页面；工作台不加载校对、报告管理或评定树；无评分不加载图表；未打开重点面板不加载其模块。
- 生产构建无新增循环依赖/运行时异常；TypeScript 未使用检查保持开启。
- 现有前端完整测试通过，新增边界/路由/图表测试通过；确认延迟与失败下的用户状态行为。
- 本批不改后端和数据库，仅运行相关前端/构建验证；不把既有后端测试冒充本轮重新运行。
- 页面、图表、面板和依赖变更可分别回退；保留旧 production dist 仅用于本轮比较，不作为运行入口回退。
