## 阅读入口

## 层级与字段结构

一般路径为“根节点 → 结构大类 → 结构类型/部件 → 构件分组 → 病害叶节点”。必须以 parent_id 为准；显示编号不能替代父子关系。6.3 是 component_group，既含 6.3.1～6.3.5 子分组，也直接挂载 4 个病害节点。病害叶节点下没有进一步的病害分类节点，标度是节点上的规则字段。

| 组成 | 字段 | 含义 |
| --- | --- | --- |
| 节点身份 | 包内 id；运行时 node_key、数据库 id | 包内稳定键与数据库实例身份；显示编号不是全局唯一键 |
| 父子关系 | 包内 parent_id；运行时 parent_node_id；path | 保存真实上下文与完整目录路径 |
| 展示 | display_number、display_name、node_type、sort_order | 编号、名称、节点类型、排序；页面优先按显式编号自然排序 |
| 适用范围 | bridge_type_ids、component_category_ids | 节点允许的桥型和构件类别；不能仅按病害名称或目录标题判断适用性 |
| 选择与计分 | is_selectable、scoring_mode；编译后 is_scoring | 区分不可选目录、可选计分病害、可选记录病害 |
| 规范引用 | h21_indicator_id、h21_indicator_name、h21_source_table | 计分节点引用的 H21 指标及条表号 |
| 标度 | allowed_scales、scale_descriptions、deduction_points | 合法标度、各级判定和单指标扣分，由锁定的 H21 包编译取得 |
| 特殊判定文字 | source_scale_descriptions；编译后 uses_source_scale_descriptions | 两个水损害节点采用来源软件判定文字，扣分继续引用 H21 |
| 来源与说明 | source_ids、sources、organization_note | 规范来源、单位来源和节点说明 |
| 来源精确对表 | source_group_id、source_indicator_id、source_group_number、source_indicator_number、target_node_id | 403 条映射；先使用来源分组 ID＋指标 ID，兼容使用来源分组编号＋指标编号 |

2.0.3 不包含旧版本的 aliases.json 或 matching-rules.json；本版本自动匹配使用结构化来源身份，不以病害名称、别名或关键词代替精确对表。已发布版本在评定树页面只读；年度绑定决定该年度实际使用哪版规则。
