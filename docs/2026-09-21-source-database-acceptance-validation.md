## 独立对账方法

1. 从快照直接读取 outerCheckData 与 taskTrees，用带重复计数的集合比较构件编号、病害位置、描述、标度、来源病害分组 ID、来源指标 ID；974 条均一致。
2. 对数量、长度、宽度、面积一的非空结构化列，比较导入尺寸的类型、值及单位。1,228 个单值和 7 个范围上下限通过；未知范围格式会令验收失败。
3. 从 images 解码每张病害图片，计算 SHA-256，再与独立归档中的实际文件及其所关联病害事实联合比较，874 张均一致。
4. 真实库回归另检查来源指标完整、构件类别非空、照片候选双向引用及解析确定性。parser_name 均为 source_db_importer，import_context.source_type 均为“接口同步”。
5. 最后重新计算原库和快照哈希。原库保持不变，未触碰来源软件业务数据。

当前合同的 source_ref.source_type 仍用 word 表示导入候选，这是既有契约兼容字段，不能据此判断走了 Word 解析器。数据路线以导入上下文和 parser_name 为准。
